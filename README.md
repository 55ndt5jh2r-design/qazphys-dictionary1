# QAZPHYS DICTIONARY ⚡

Қазақша – Орысша – Ағылшынша физика терминдерінің заманауи интерактивті сөздігі және ҰБТ-ға дайындық платформасы.

## Мүмкіндіктері
- **110+ Физика термині**: Механика, Молекулалық физика, Электродинамика, Оптика, Кванттық және Атомдық физика бөлімдері.
- **Үштілді іздеу**: Қазақ, орыс, ағылшын тілдерінде жылдам сүзгілеу.
- **Формулалар мен Өлшем бірліктері**: Әр терминге нақты формула, ХБЖ (СИ) өлшем бірлігі және мысалдар.
- **Флеш-карталар және ҰБТ Тест режимі**: Терминдерді жаттауға арналған интерактивті тренажер.
- **AI Физика Көмекшісі**: `/api/explain` серверлік функциясы арқылы терминдерді тереңдетіп түсіндіру.
